# Codex Monitor 正六边额度表盘品牌设计

## 背景

现有“余量窗口”图标容易被理解为照片、相册或液面工具，无法直接表达 Codex
额度计算。后续尝试过交织结、六向结和双带结构，但这些方向存在三个问题：

1. 与 ChatGPT 标志过于相似，容易产生官方产品联想。
2. 为了同时表达交织与额度，图形在 18px 菜单栏尺寸下过于复杂。
3. 部分方案只能依赖颜色表达消耗比例，单色模板图标无法可靠读取。

本设计采用“正六边额度表盘”，以独立的计算监控语言替代 ChatGPT 式花结。
本文件只替换原品牌设计说明中的图标部分，不改变已经确认的额度、会话与菜单栏
功能。

## 设计目标

图标需要同时满足：

- 第一眼可理解为额度、计量或状态表盘；
- 正六边骨架严格同心、旋转对称；
- 彩色与单色环境都能表达当前消耗位置；
- 在 18px 菜单栏尺寸下保留清楚轮廓；
- 与 ChatGPT、Codex Pacer 和照片类应用保持明显区别；
- 可以由一份矢量母版导出 macOS、Windows、前端和菜单栏资源。

## 视觉结构

### 正六边轨道

主轮廓是同心正六边形轨道。六条边长度一致，六个顶点位于同一外接圆，轨道使用
一致带宽与圆角连接。

轨道同时承担品牌轮廓和总额度语义，不在 Logo 外再增加额外进度环。起点固定在
十二点方向，进度沿顺时针增长。

### 六个主刻度

六个顶点各有一个向内刻度。刻度从轨道中切出，保持统一长度、宽度和圆头。
主刻度用于强化表盘读法，也让单色小图在没有数字时仍能建立方向。

最终矢量允许为 18px 版本减少刻度长度，但不能改变刻度数量和位置。

### 指针与轴帽

指针采用钟表式结构：

- 一体成形的圆头长针；
- 穿过轴心的短配重；
- 小尺寸圆形轴帽覆盖连接；
- 不使用三角箭头、独立箭头尖或巨大中心圆环。

指针端点落在内侧刻度附近，不接触外轨道。配重明显短于长针，避免图形被误读为
一条普通对角线。

### 光学修正

数学中心是起点，最终输出允许进行以下光学修正：

- 轴帽相对几何中心移动不超过母版宽度的 0.5%；
- 指针长端和短配重分别微调不超过母版宽度的 1%；
- 六边轨道圆角在相同数值基础上做像素网格适配；
- 18px 模板版可将轨道与指针加粗，但必须保持相对比例。

所有修正必须在 1x、2x 和 3x 输出中分别检查，不能只看放大稿。

## 额度语义

### 彩色状态

完整轨道先绘制暖白色总量层，再从十二点方向顺时针覆盖薄荷色消耗层。覆盖长度
等于 `consumed_percent`，限制在 0% 到 100%。

指针角度使用同一百分比：

```text
angle = -90deg + consumed_percent * 360deg
```

轨道覆盖终点与长针方向必须一致，不能出现颜色到达一个位置而指针指向另一个位置。

### 单色状态

菜单栏模板图标不能只依赖薄荷色。它使用三种形态共同表达状态：

1. 总额度轨道使用较细、较低不透明度的完整轮廓。
2. 已消耗轨道使用较粗、完全不透明的覆盖段。
3. 指针落在覆盖终点。

因此在黑色、白色或系统着色环境中，用户仍能区分 20%、50% 和 80%。0% 与
100% 虽然指针方向相同，但轨道覆盖宽度和不透明度完全不同，不会产生歧义。

若目标平台不支持模板图标内的多级不透明度，退化为“细总量轨道 + 粗消耗轨道”，
不能退化为只显示一根指针。

### 无数据与陈旧状态

- 尚无账号数据：显示完整细轨道，不显示消耗覆盖，指针停在十二点。
- 数据陈旧：保留最后状态，在轴帽右上增加一个独立小缺口，不添加问号文字。
- 刷新中：不旋转指针，不播放持续动画；菜单文字负责说明刷新状态。

品牌主图标使用固定的示意状态，不代表实时账号数据。只有菜单栏状态图标和产品内
额度图形绑定实时百分比。

## 色彩

主色保持现有界面的森林绿与薄荷绿体系：

- 底板：深石墨绿，不使用纯黑；
- 总量轨道与指针：暖白，不使用纯白；
- 消耗覆盖：克制的薄荷绿；
- 轴帽内芯：与底板同色。

不使用彩虹渐变、霓虹外发光、金属高光或多种状态色。警告和危险阈值仍由产品界面
表达，不改变品牌主图标颜色。

## 平台资产

### 彩色应用图标

- macOS 与 Windows 使用深色圆角底板；
- 六边表盘位于视觉中心，四周留出安全区；
- 默认导出 16、32、64、128、256、512 和 1024px；
- 16px 与 32px 使用专门的小尺寸母版，不直接缩放 1024px 版本。

### macOS 菜单栏模板

- 仅包含六边轨道、六个刻度、指针和轴帽；
- 不包含底板；
- 以 alpha 蒙版表达粗细与不透明度；
- 同时验证浅色、深色和高对比菜单栏。

### 前端品牌标志

侧栏与关于页使用静态彩色版本。产品内实时额度图形继续采用业务组件，不直接把
应用图标当作图表使用。

## 动态与性能

菜单栏百分比变化时，指针和轨道可以在 180ms 到 240ms 内平滑更新。动画采用
临界阻尼，不回弹，不绕表盘多转一圈。跨越 100% 到新周期 0% 时直接短交叉淡化，
避免反向扫过整个表盘。

减少动态效果开启时，轨道与指针立即切换到新值，仅保留颜色和线宽变化。

每次更新应复用同一矢量模板或缓存后的离散图标，不在主线程高频重绘。账号刷新
频率远低于动画帧率，图标不承担连续实时仪表职责。

## 测试与验收

### 视觉测试

- 0%、20%、50%、80% 和 100% 五个状态；
- 彩色、纯黑、纯白和系统模板着色；
- 18、22、32、64、128 和 1024px；
- macOS 浅色、深色和高对比菜单栏；
- 与 ChatGPT、Codex Pacer 和常见照片应用图标并排检查轮廓差异。

### 语义测试

- 不看颜色时能区分 20%、50% 和 80%；
- 指针方向与消耗轨道终点一致；
- 0% 与 100% 可由轨道形态区分；
- 无数据状态不会伪装成 0% 已消耗；
- 静态品牌图标不会被误解为当前账号状态。

### 完成标准

1. 指针为连续钟表式表针，没有三角箭头毛刺。
2. 基础六边骨架与六个刻度严格同心、旋转对称。
3. 单色模板图标不依赖颜色也能表达额度比例。
4. 18px 下轨道、指针和轴帽仍可分辨。
5. 图标不再使用交织花结、窗口液面或声波结构。
6. 所有平台资产由同一矢量系统导出并通过视觉回归检查。
